# 📚 Ответы к экзамену «Нейронные сети» (СГАУ, лето 2025/26)

Тезисы для **устного** ответа: коротко, на пальцах, с пометками источников, аналогиями,
ASCII/SVG-схемами и примерами кода. По одному файлу на вопрос.

> ⚠️ **Вопроса 13 нет** — в списке препода нумерация идёт `…12, 14, 15…` (пропуск у препода).
> Всего вопросов — **19**.

---

## 🧭 Как пользоваться

- **Читать ответ** — открой нужный `qNN.md` (ссылки ниже).
- **Видеть схемы** — открывай в **VS Code / Cursor** через предпросмотр Markdown (`Cmd/Ctrl+Shift+V`)
  или смотри на **GitHub** — SVG-картинки отрисуются. Сами схемы лежат в [`img/`](img/).
- **Подсказки от ИИ** — скопируй [**`ВСЁ-В-ОДНОМ-для-чата.md`**](ВСЁ-В-ОДНОМ-для-чата.md) целиком и
  вставь в ChatGPT/Claude/GigaChat первым сообщением: бот станет репетитором по этим материалам
  (там схемы в виде ASCII, чтобы видно было прямо в чате).

Структура каждого ответа: 🎯 шпаргалка → суть → тезисы (с источниками) → аналогия → схема → код →
блок «вне источников».
